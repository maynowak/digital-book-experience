## Current Technical Highlight: Book Presentation

The book presentation was structurally refined so that the published cover is treated as the content of a dedicated print surface:

```text
coverSurface
└── coverPrint
    └── coverHolder
        └── img.cover
```

This separates the physical-material simulation from the replaced `<img>` element.

The architecture allows:

- hardcover material effects on the surrounding surface
- controlled inset material edges
- clean image rendering
- future interaction refinements
- more predictable stacking and rendering behavior
